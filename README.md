# Resumistic 🚀

An intelligent, AI-powered application designed to analyze, score, and optimize professional resumes. Resumistic goes beyond standard resume checkers by parsing complex documents and offering unique, actionable insights to help candidates stand out to recruiters and Applicant Tracking Systems (ATS).

## 🌟 What Makes Resumistic Unique?

**🔥 The "Roast Mode" (Dark Mode Exclusive)**
Tired of generic, sugar-coated feedback? Switch the application to Dark Mode to activate **Roast Mode**. Our AI will brutally and humorously tear down your resume, highlighting major red flags 🚩 and delivering the "harsh truth" about how a strict recruiter might actually view your experience. It's a fun, engaging, and highly effective way to catch critical mistakes before an employer does!

**📄 Intelligent Document Parsing**
Unlike basic tools that struggle with formatting, Resumistic features robust PDF and DOCX parsing capabilities directly integrated into the backend. It accurately extracts and processes text from uploaded resume files, ensuring the AI analyzes your actual content without losing context.

## Core Capabilities

- **ATS Evaluation**: Get a precise compatibility score to understand exactly how well your resume performs against automated screening systems.
- **Detailed AI Analysis**: Receive immediate, AI-driven insights categorized into key strengths, areas for improvement, and highly actionable suggestions.
- **History Tracking**: Securely store, review, and manage past resume analyses through a personal dashboard.
- **Tailored Resume Generation**: Provide a target job description or select from industry-standard templates to generate a custom-tailored, highly relevant resume.

## Tech Stack 🛠️

Built for performance, scalability, and a premium user experience:
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Framer Motion (for smooth, modern UI interactions)
- **Authentication**: NextAuth.js (Secure OAuth Integration)
- **Database**: Supabase
- **Package Manager**: pnpm

## Architecture Overview

The application follows a modular Next.js architecture. The frontend provides a stunning, modern UI with smooth client-side animations handled via Framer Motion. Secure backend API routes handle the heavy lifting: complex file parsing, AI model communication, and database transactions with Supabase, ensuring a highly responsive and premium user experience.
